# Testing

The initial migration gate covers exhaustive module classification, manifest honesty, portable-record parsing,
malformed/singular failures, residual evidence, and legacy/canonical P1 parity. Existing focused mesh, FEM,
capability, and problem-adapter tests guard the preserved surface.

Passing this gate does not establish broad solver correctness. Each specialist capability retains analytical,
manufactured, convergence, stability, derivative, posterior, calibration, and backend-specific evidence requirements.
