# mixle-pde documentation

This folder holds package-local documentation for PDE, ODE, simulator, and
mechanistic-verification surfaces. Keep these docs in `mixle-pde` rather than
the core `mixle` repository.

## Guides

- [0.6.x field modeling capabilities](0.6.x-field-modeling.md): 3D/4D latent
  fields, observations, priors, linear and bounded inversion, assimilation,
  geoscience likelihoods, posterior queries, mesh support, and readiness
  checks.
