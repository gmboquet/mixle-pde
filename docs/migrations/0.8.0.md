# Migration to 0.8.0

Existing PDE imports and solver calls remain supported. Use `migration_inventory()` to inspect each module's planned
disposition/final owner and `native_backend_manifest()` before selecting canonical execution. New P1 callers may use
`solve_p1_poisson_canonical()` to obtain the legacy-compatible result plus mesh, finite-system, residual, conversion,
backend, and parity evidence.

No artifact or API is rewritten or removed automatically. Later migrations require explicit adapters, caller parity,
deprecation documentation, and an evidence window.
