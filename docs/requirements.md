# Requirements

- Preserve verified public behavior or provide an explicit, tested migration/deprecation path.
- Classify every shipped module by disposition and final semantic owner.
- Advertise backend support only when an executable scenario establishes it.
- Consume versioned public artifacts and reject unsupported features without silent fallback.
- Bind source identity, conversions, backend capability, residuals, limitations, and parity in receipts.
- Keep inverse/posterior claims tied to immutable model, data, prior, likelihood, algorithm, and diagnostic evidence.
