# Contracts

`CON-MATH-PROBLEM-V1` dictionaries are inspected through explicit `PDEBackendProfile` capabilities.
`mixle.sim.finite-linear-system/v1` is the initial executable canonical boundary: exact rational coefficients, unique
unknown names, square dimensions, and a SHA-256 source identity. The native adapter reports an approximate float64
outcome with checked residual, not an exact mathematical certificate.

The native backend manifest is versioned and content-addressed. Existing PDE objects remain compatibility surfaces;
they do not become canonical cross-project contracts merely because adapters can translate them.
