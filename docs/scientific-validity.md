# Scientific validity

A low algebraic residual establishes only the executed finite system, not continuum convergence, physical validity,
identifiability, posterior calibration, or data fitness. Legacy parity establishes compatibility, not independent
correctness. Receipts therefore label coefficient conversion and evidence strength and retain limitations.

The initial canonical adapter is a dense float64 execution path for exact-rational linear records. The P1 wrapper is
limited to scalar source/conductivity on supplied simplex meshes. Broader PDE/FEM/inverse claims rely on their existing
named scenarios and future cross-project conformance gates.
